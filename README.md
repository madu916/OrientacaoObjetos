## Aplicação de POO em um jogo 🕹️

Este projeto foi desenvolvido em aula, acompanhando o professor.

Nesse jogo o usuário irá decidir o nome do personagem mágico, o nome da habilidade mágica, 
nível de energia do personagem e o consumo de energia da habilidade.
Após isso:
- O case 1, o usuário decide se a habilidade estará ativada ou não;
- No case 2, é onde exibe as informações do personagem que foram dadas pelo usuário;
- No case 3, é digitado o nome do ataque;
- Case 4, é pedido para inserir o nível de energia e depois é exibido o nível de energia atual;
- No case 5, a habilidade é ativada;
- o case 0 irá finalizar o programa.

Enquanto o usuário não selecionar a opção 0, o loop irá continuar.
